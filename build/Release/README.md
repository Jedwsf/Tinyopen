# Tinyopen

> 一个轻量的 Windows 桌面小工具：把常用的**文件、程序、网页**分组收纳，一键批量打开。

**版本 1.2.1　·　适用平台：64 位 Windows 10 / 11　·　绿色免安装**

---

## 简介

Tinyopen 用来解决一个很日常的烦恼：每天开工要打开一堆固定软件、文档和网页，一个个点太麻烦。

用它把「上班要开的东西」放进一个分组，以后点一下就能全部打开；把「追的番」放一组，把「工作网页」放一组，互不干扰。

- 🟢 **绿色便携**：免安装，整个文件夹拷到 U 盘也能用
- 🧩 **分组管理**：文件 / 程序 / 网页都能放进分组，一键启动
- 🖱️ **拖动排序**：按住分组标题栏即可拖动换位置
- ⚡ **开机自启**：可让指定分组在 Tinyopen 启动时自动打开
- 📝 **后台记录**：每次打开成功还是失败，都有据可查

---

## 功能特性

| 功能   | 说明                                                              |
| ---- | --------------------------------------------------------------- |
| 分组管理 | 新建 / 重命名 / 删除分组；分组内可放任意数量的文件或网页                                 |
| 一键启动 | 点分组的「播放」按钮，按「启动间隔」依次打开组内全部内容                                    |
| 拖动排序 | 按住分组标题栏上下拖动，出现蓝色插入线，松手即换位（自动保存）                                 |
| 开机自启 | 每个分组可单独开启；开启后随 Tinyopen 启动自动打开该组                                |
| 打开网页 | 路径栏支持 `http://` `https://` `ftp://` 及 `www.` 开头（自动补 `https://`） |
| 自动命名 | 新分组加入第一个文件后，自动以文件名命名                                            |
| 拖拽添加 | 文件拖到空白处 → 新建分组；拖到分组里 → 加进该组                                     |
| 后台记录 | 记录每次打开的结果（成功 / 失败 / 原因），保存在本地                                   |
| 绿色便携 | 配置与日志都在程序目录，整个文件夹拷走即可迁移                                         |

## 快速开始

1. 把整个文件夹拷到电脑任意位置，例如 `D:\Tinyopen`
2. 双击 **`Tinyopen.exe`** 运行
3. 点右上角 **加号** 新建分组 → 点分组里的 **加号** 添加文件或网页 → 完成

> ⚠️ **请连同整个文件夹一起拷贝**，不要只拷 `Tinyopen.exe`。  
> 程序需要旁边的 `.dll` 文件和 `platforms` 等子文件夹才能启动。

## 使用说明

### 主界面

顶部工具栏从左到右：

| 图标 | 名称   | 作用                       |
| -- | ---- | ------------------------ |
| ➕  | 新建分组 | 新建一个空分组                  |
| ⚙️ | 设置   | 打开设置（启动间隔、版本号）           |
| 🕐 | 状况   | 查看后台记录（本次运行打开了什么、成功还是失败） |

### 分组

每个分组有一个标题栏，右侧有四个按钮：

| 图标      | 名称   | 作用                       |
| ------- | ---- | ------------------------ |
| 🔌 电源   | 开机自启 | 开启 / 关闭该分组的开机自启（灰=关，绿=开） |
| ➕ 加号    | 添加   | 向本组添加一个文件或网页             |
| ▶️ 播放   | 启动分组 | 打开本组里的全部文件               |
| 🗑️ 垃圾桶 | 删除分组 | 删除本分组                    |

其他操作：

- **改名**：点击分组名即可编辑
- **换位置**：按住分组标题栏拖动，蓝色插入线指示落点，松手即插入
- **自动命名**：分组还叫「新分组」时，加入第一个文件会自动按文件名改名

### 文件行

每一行从左到右是：**类型图标 → 名称 → 启动按钮 → 删除按钮**

- **双击**某一行可以编辑它（显示名称、路径/网址、启动参数）
- 类型图标会自动识别：网页 🌐、图片 🖼️、音乐 🎵、程序 📦、文档 📄、文件夹 📁

### 拖拽

| 拖到哪       | 效果          |
| --------- | ----------- |
| 窗口空白处     | 每个文件各新建一个分组 |
| 某个分组里     | 直接加入该分组     |
| 分组标题栏（按住） | 给分组换位置      |

## 开机自启

按分组单独设置：

- 点分组标题栏的 **电源图标** 开启 / 关闭
- **灰色** = 关闭（默认）　**绿色** = 开启
- 开启后，每次打开 Tinyopen 会自动打开该组里的全部文件
- 多个分组都开启时，会依次打开（文件之间按「启动间隔」等待）

---

## 路径与网址

「路径/网址」栏同时接受两类内容：

| 类型   | 示例                              | 打开方式   |
| ---- | ------------------------------- | ------ |
| 本地文件 | `C:\Users\...\music.mp3`        | 系统默认程序 |
| 网页地址 | `https://www.bilibili.com`      | 默认浏览器  |
| 简写网址 | `www.baidu.com`（自动补 `https://`） | 默认浏览器  |

支持的网址前缀：`http://`、`https://`、`ftp://`、`ftps://`、`www.`

---

## 设置

点顶部 **齿轮** 图标打开：

- **启动间隔**：每次启动一个文件前等待的毫秒数。一次要开很多程序时，适当加大可避免卡顿。注意，启动间隔是加在启动文件之前的，而且会使整个程序暂停。
- **版本号**：显示当前版本。

---

## 配置文件与日志

程序运行后会在**自身所在目录**自动生成两个文件：

| 文件            | 作用                       |
| ------------- | ------------------------ |
| `config.json` | 保存所有分组、文件、设置。删除它会恢复初始状态  |
| `tinylog.txt` | 后台记录，**只记本次运行**，每次启动清空重记 |

## 常见问题

**Q：双击没反应？**  
A：确认是把**整个文件夹**拷过来的，里面的 `.dll` 文件都在。若被杀毒软件拦截，加入信任即可。

**Q：打开某个文件失败？**  
A：点顶部 **时钟** 图标查看后台记录，会写明失败原因（如「文件不存在或路径无效」）。

**Q：能放 U 盘里用吗？**  
A：可以，本程序绿色便携，整个文件夹拷走即可。

**Q：分组顺序会保存吗？**  
A：会。拖动换位后立即保存，下次打开保持同样顺序。

**Q：怎么彻底重置？**  
A：删除程序目录下的 `config.json`，重启程序即恢复初始状态。
